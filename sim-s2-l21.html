L21 訪談工具箱 Lesson 21 · Interview Toolkit — 社區實測：探訪／訪問

玩法 How to play： 1️⃣ 填好受訪者資料 → 2️⃣ 加入 5–6 條問題（系統自動檢查引導式／封閉式）→ 3️⃣ 按「開始」進行 15 分鐘訪問 → 4️⃣ 用三欄表記低用家回應＋重點，標記有無具體事例 → 5️⃣ 匯出文字記錄交功課。
Fill in the interviewee profile, draft 5–6 questions (auto-checked for leading/closed questions), run the 15-minute timer, take 3-column notes, then export.

1 · 受訪者資料 Interviewee profile

2 · 問卷設計器 Questionnaire builder 0 / 6 條

三原則：開放式為主、不問引導式問題、由淺入深 5–6 條。加入問題後系統會即時檢查。
Principles: mainly open-ended, no leading questions, easy-to-deep, 5–6 questions.

檢查說明： ⚠️ 引導式 問題暗示了答案（例：含「係咪／是不是」）→ 重寫！ 🔒 封閉式 只能答係／否 → 盡量改開放式。 ✅ 開放式 用家用自己說話回答 → 好！ ➖ 中性 可再開放啲（加「什麼／點樣／舉例」）。

3 · 訪問計時 Session timer（15 分鐘）

15:00

時間到會響鈴。先問日常問題建立關係，再問產品問題。Chimes at 0:00. Start with daily-life questions, then product questions.

4 · 追問提示卡 Probing prompts

用家答得值得深入，撳卡即睇追問句式。Tap a card when an answer deserves follow-up.

🔍 舉個例子
Ask for an example
📍 什麼情況下
Find the context
⚡ 多大不便
Judge urgency
🎭 拆解客套話
Dig past politeness
撳上面卡片，追問句式會喺度放大顯示。
Tap a card — the probe appears here, large.

5 · 三欄訪問記錄 3-column notes 0 項回饋

提問／用家回應／重點摘要。重點摘要填好即計為一項回饋（目標 ≥3 項）。只有附帶具體事例的回應先係可靠設計依據！
Question / response / key points. Only responses with concrete examples count as design evidence.

6 · 匯出記錄 Export
