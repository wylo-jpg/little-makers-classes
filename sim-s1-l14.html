L14 互動模擬：Debug 大作戰 Debugging Challenge — reproduce → trace → fix

玩法 How to play
  1. 揀一個情境（甲／乙／丙／丁），每組指令都收埋咗蟲 bug。
    Pick a scenario — each instruction set hides bugs.
  2. ① 重現：撳「重現問題」睇機械人行到邊度出事。② 追蹤：睇追蹤表，撳 🐞 圈出錯嘅一步，再揀錯誤類型。③ 修正：用編輯工具改指令。④ 測試：撳「重新測試」驗證！
    Reproduce → trace & flag the bug → fix → re-test.
  3. 四種蟲：次序錯誤、遺漏步驟、含糊用詞、多餘步驟。
    Four bug types: wrong order, missing step, vague wording, redundant step.
